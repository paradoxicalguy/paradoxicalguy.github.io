process

how i investigate build differences

the process is usually mechanical: reproduce the mismatch, narrow the artifact, inspect the relevant format, then fix the earliest unstable input.

  1. 01
    rebuild

    use the same source in intentionally different paths or environments.

  2. 02
    compare

    check hashes and isolate the first artifact that differs.

  3. 03
    inspect

    open archives, crate metadata, objects, dwarf, codeview, pdb data, or symbols.

  4. 04
    localize

    find the flag, path, record, or build input responsible for the difference.

  5. 05
    regress

    fix the cause and encode the expected behaviour in a test where it makes sense.
