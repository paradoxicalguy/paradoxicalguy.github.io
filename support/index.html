▣ EQUIPMENT / 02

The problem isn't motivation.

I work through tight edit–compile–inspect loops. For compiler and reproducibility investigations, being able to change one thing and test it immediately on my own machine matters. My current laptop is increasingly unable to support that workflow.

▥
Display damage

Large vertical artifacts, spots, and damaged pixels make day-to-day use difficult.

⚡
Unexpected shutdowns

My laptop sometimes powers off during work, even when I try to keep it cool.

▤
Storage and RAM pressure

Rust artifacts and WSL2 pushed storage as low as roughly 200 MB free; I ended up removing WSL2 to keep working.

↻
Remote CI isn't my normal dev loop

I've used GitHub Actions extensively. It helps, but it doesn't replace rapid local experimentation.

Why no photos here? I prefer to keep hardware photos private. If you're seriously considering helping, I'm happy to share additional details and evidence directly.
★ PREFERRED EQUIPMENT

New 14-inch MacBook Pro

This is a considered preference, not an ultimatum or a status-symbol request. I carry my machine daily, need enough memory and storage for toolchains and build artifacts, and value active cooling for sustained work.

  • Portable 14-inch form factor
  • Active cooling for longer builds
  • 24 GB+ unified memory preferred
  • 1 TB storage preferred
  • New hardware for dependable long-term ownership

A direct device donation, partial funding, or alternative *new* hardware proposal that genuinely fits these needs is welcome. Some reproducibility work also requires a Linux/x86-64 environment; a Mac doesn't remove that requirement.
